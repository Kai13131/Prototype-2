# Prototype 2

1. what went well?
   I made a basic dice battle system. The player can press the Roll button, roll a random number from
   1-6, and use the result as damage to the enemy, and the enemy can also attack back like a turn
   base.
2. What didn't go well?
   Some parts of the code didn't work well on the first try, especially moving the glow between the
   dice. Unity always has some bugs, I don't if that was my problems.
3. What challenges did you face?
   To get a better understanding how to use Coroutine and RectTransform. Using them to create the
   dice animation was challenging.
4. What can you do differently next time?
   I think I can make the battle more interesting by adding actions, abilities and animations.
